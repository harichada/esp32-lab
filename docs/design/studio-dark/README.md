# Studio Dark reference mockups

These pages are visual references for the `?ui=3` workbench. They were reconstructed from the approved design notes (near-black canvas, floating cards, violet-to-cyan accent on Run and selected states, tidy schematic, welcome bento). The original mockup generator was not in this repository.

Open the HTML files in a browser and compare them with the running app at `/?ui=3`.

| File | What it shows |
|---|---|
| `desktop-workbench.html` | Desktop workbench, simulation running |
| `desktop-welcome.html` | First-run welcome |
| `phone-workbench.html` | Phone workbench, 390×844 |
| `phone-menu.html` | Phone More sheet |

Nothing here is loaded by the app. There is no AI prompt, no account, and no network call.
