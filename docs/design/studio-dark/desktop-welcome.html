Blink tour

Five steps on a real ESP32 DevKit. The tidy schematic stays available beside the breadboard.

  1. Add an LED.
  2. Add a resistor.
  3. Wire GPIO2 to the resistor, the resistor to the LED, and the LED to GND.
  4. Open the sketch.
  5. Run and watch the LED turn on and off.
